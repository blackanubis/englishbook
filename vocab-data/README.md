## 使用方法

1. 双击 `index.html` 在浏览器打开网页
2. 点击顶部导航【设置】
3. 滚动到【导入 / 导出】区域，点击"📥 导入学习记录"
4. 选择本目录下任意 JSON 文件
5. 系统会显示"导入成功"，词库自动合并
6. 重复操作可逐个导入所有 JSON 文件

## 词条格式

每个 JSON 文件结构：
```json
{
  "customVocab": {
    "enlighten": [
      {"level":"启蒙","word":"apple","phonetic":"/ˈæpl/","chinese":"苹果","example":"I eat an apple.","tags":"水果"}
    ]
  }
}
```

支持一次导入多个等级（即将所有等级放入一个 `customVocab` 对象中），导入逻辑会自动去重。

## 注意事项

- 导入会**追加**到现有词库，不覆盖已有词条
- 同名（相同 word + level）会自动跳过
- 江苏特色等级不需要导入此目录文件，已内置
